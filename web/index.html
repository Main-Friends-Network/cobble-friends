Cobble Friends

Was ist Cobble Friends?

Cobble Friends ist ein Modpack für Minecraft, das von der Minecraft-Friends-Community entwickelt wurde. Es bietet einen Fokus auf Cobblemon und Create und kombiniert diese mit einer Vielzahl von anderen Mods, um ein einzigartiges Spielerlebnis zu schaffen.


Das Modpack ist für die Minecraft-Version 1.21.1

Modpack Features

Cobble Friends bietet eine Vielzahl von Mods, die das Spielerlebnis erweitern. Hier sind einige der wichtigsten Features:

  • Integration von Cobblemon für Pokémon-Fans
  • Erweiterte Automatisierungsmöglichkeiten mit Create
  • Optimierte Performance und Stabilität
  • Regelmäßige Updates und Bugfixes

Installation

Um Cobble Friends zu installieren, benötigst du den Prism Launcher.

Installiere dir den Prism Launcher von prismlauncher.org und füge das Modpack hinzu, indem du die folgenden Schritte befolgst:


  1. Öffne den Prism Launcher.
  2. Klicke auf "Instanz erstellen" in der oberen Leiste.
  3. Wähle "Importieren".
  4. Gib die URL des Modpacks ein: https://cobble.minecraft-friends.de/modpack/Cobble%20Friends.zip (will be later on changed to GitHub latest release)
  5. Klicke auf "OK".
  6. Starte das Modpack.
